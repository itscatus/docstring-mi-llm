# Docstrings Distort Maintainability Index Scores

Replication package for the paper *"Docstrings Distort Maintainability Index Scores in the Evaluation of Code Generated by Large Language Models"*.

The study examines how the Maintainability Index (MI) behaves on the reference solutions of HumanEval, MBPP and BigCodeBench, and whether docstrings supplied by the benchmark prompt change the conclusion of a comparison between LLM-generated and human-written code.

## Contents

| Path | Description |
|---|---|
| `analysis.ipynb` | Single notebook that reproduces every number, table and figure in the paper |
| `results/metrics_all.csv` | Static metrics and four MI variants for all HumanEval and MBPP reference solutions |
| `results/humaneval_docstring_ablation.csv` | HumanEval programs measured with and without docstrings |
| `results/bigcodebench_metrics.csv` | Static metrics and MI variants for BigCodeBench reference solutions |
| `results/bigcodebench_docstring_ablation.csv` | BigCodeBench programs measured with and without docstrings |
| `results/stats.json`, `results/stats_bigcodebench.json`, `results/stats_llm.json` | All statistics reported in the paper |
| `results/llm_results.csv` | Per-problem results of the LLM comparison (unit tests, MI under P1-P3) |
| `results/llm_raw.jsonl` | Raw responses of the three LLMs for the 164 HumanEval problems |
| `figures/` | Figures used in the paper |

## How to run

1. Open `ISRITI.ipynb` in Jupyter or Google Colab.
2. Run all cells. The first cell installs `radon==6.0.1`, `scipy`, `numpy`, `pandas`, `matplotlib` and `pyarrow`.
3. The benchmarks are downloaded automatically into `data/`.

Sections 1-9 (reference-solution analysis) need no API key and run in a few minutes.
Section 10 generates the LLM solutions. It skips any problem already present in `results/llm_raw.jsonl`, so with the included file **no API calls are made**. To regenerate the responses, add `GEMINI_API_KEY` and `GROQ_API_KEY` as Colab secrets.

## LLMs

Solutions were generated on 11-12 November 2026 with default sampling settings:

- `gemini-3.5-flash-lite` (Google, via Google AI Studio)
- `openai/gpt-oss-120b` (OpenAI, open weights, via Groq)
- `qwen/qwen3.8-27b` (Alibaba, open weights, via Groq)

## Measurement protocols (RQ4)

- **P1**: radon MI on both programs as they are (the common protocol)
- **P2**: radon MI after removing docstrings from both programs
- **P3**: Visual Studio MI (no comment term) on both programs as they are

## Environment

radon 6.0.1; Python 3.12 and 3.13 produce identical results.
